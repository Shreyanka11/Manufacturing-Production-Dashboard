# Manufacturing Production Dashboard

## Project Overview
An interactive Business Data Analytics dashboard for analysing manufacturing productivity using a public garment industry dataset.

## Objectives
- Analyse actual versus targeted productivity.
- Compare productivity across departments and teams.
- Examine overtime, idle time, and work in progress.
- Identify productivity gaps and provide data-driven recommendations.

## Tools
- Microsoft Power BI Desktop
- Power Query
- DAX
- Git and GitHub

## Dataset
Source: [UCI Machine Learning Repository — Productivity Prediction of Garment Employees](https://archive.ics.uci.edu/dataset/597/productivity)

The dataset will be downloaded separately. Consult its source and license before redistribution.
